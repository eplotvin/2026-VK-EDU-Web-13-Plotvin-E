# Домашнее задание 1 — верстка сайта

## Как открыть верстку

Верстка находится в папке `public/`. Откройте файл `public/index.html` в браузере.

## Страницы

- index — список вопросов (главная)
- question — страница вопроса с ответами
- ask — добавление вопроса
- login — вход
- signup — регистрация
- profile — профиль пользователя
